# 百年修得同船渡 · 人设图索引

十世,每世一对(男主 182cm 结实体型 / 女主 170cm 纤细)。每张是**黑白铅笔三栏设定稿**:左=面部特写,中=全身正面,右=全身背面。同一男主、同一女主贯穿十世,只换服装发型。

## 用法(给出视频的 agent)

- 每镜以对应世的 `男主.png` / `女主.png` 当**参考图**,prompt 里写「只借用长相五官,服饰照人设图」。
- 人设是**黑白铅笔稿**;真人视频要写实时,按 Seedance 规则「参考图是铅笔素描画稿,还原成写实照片风格」。CG/幻想世(神话/仙侠/海盗/蒸汽/赛博/星际)可直接当写实参考,不受真人检测限制。
- **前九世不给正脸**(脚本制作要点):镜头只给背影/侧影/手/半张脸。正脸留到第10世镜35。人设图的正脸只用于锁五官,不代表镜头要给正脸。

## 眼镜规则(重要)

男主原型戴方形近视镜。**神话~民国(1-7世)一律不戴眼镜**,人设图已按此出。赛博(8)、星际(9)可戴目镜/HUD。当下(10)戴回近视镜。

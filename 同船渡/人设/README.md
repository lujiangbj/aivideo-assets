# 百年修得同船渡 · 人设图索引

十世,**同一对男女主贯穿始终**,只换身份服装。每张是**黑白铅笔三栏设定稿**:左=面部特写,中=全身正面,右=全身背面。

## 用法(给出视频的 agent)

- 每镜以对应世的 `男主.png` / `女主.png` 当**参考图**,prompt 写「只借用长相五官,服饰/身份道具照人设图」。
- 人设是**黑白铅笔稿**;真人视频要写实时,按 Seedance 规则「参考图是铅笔素描画稿,还原成写实照片风格」。CG/幻想世(神话/仙侠/海盗/蒸汽/赛博/星际)可直接当写实参考,不受真人检测限制。
- **前九世不给正脸**(脚本制作要点):镜头只给背影/侧影/手/半张脸,正脸留到第10世。人设图的正脸只用于锁五官。

## 本片戏核:阶层/立场差

每世男女主的**阶层或立场差**要一眼看出,这是戏核。不是穿对朝代衣服就行——两人**不能画成同一阶层同一气质**。见下表「阶层差」列。

## 铁律

- **脸严格照原型,一眼是同一个人**。男主:脸偏方正、下颌线清楚、眼睛不大但沉静、鼻梁直、嘴唇偏薄。女主:鹅蛋脸略圆润、大眼双眼皮明显、鼻梁直挺鼻头小巧、嘴唇偏薄清秀。⛔ 不许美化/瘦脸/放大眼睛/网红脸/动漫化。
- **女主辨识线**:黑长直中分 + 空气刘海,尽量保住(束发世可挽起但保留刘海)。
- **眼镜**:男主原型戴方形近视镜。**神话~民国(1-7世)不戴**;赛博(8)半框数据目镜、星际(9)飞行目镜可戴(是额外装备,非日常近视镜);当下(10)戴回方形近视镜。
- **玉玦彩蛋线**:男主随身带半圆玉玦(要画清是「断了一半的圆环」),挂法逐世不同(见末列)。女主那半贴身收着,不必每张显露。
